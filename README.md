# ✦ Passaporte para o Futuro

Versão web do projeto **Passaporte para o Futuro**, desenvolvido a partir de um projeto.

A aplicação transforma a jornada de desenvolvimento pessoal e profissional em uma experiência digital dividida em **seis estações e 20 etapas**:

| Estação | Tema                 | Etapas | Descrição                                                                   |
| ------- | -------------------- | ------ | --------------------------------------------------------------------------- |
| **01**  | **Identidade**       | 01–03  | Minha marca, minha mensagem e minha história.                               |
| **02**  | **Autoconhecimento** | 04–10  | Experiências, sentimentos, sonhos e projeto de vida.                        |
| **03**  | **Espelho**          | 11–14  | Momentos marcantes, pessoas que admiro, pontos fortes e como sou percebida. |
| **04**  | **Descobertas**      | 15–16  | Habilidades que reconheço em mim e aquelas que quero desenvolver.           |
| **05**  | **Futuro**           | 17–19  | Planejamento de objetivos, linha do tempo e como posso "Ser Mais".          |
| **06**  | **Carreira**         | 20     | Empregabilidade, empresas de interesse e próximos passos profissionais.     |

## ✦ Tecnologias

* **HTML5**
* **CSS3**
* **JavaScript**
* **Google Fonts**

O projeto utiliza **CSS Grid, Flexbox, responsividade, gradientes, animações e microinterações**, criando uma interface moderna, leve e adaptada a diferentes dispositivos.

## ✦ Objetivo

Transformar uma atividade de autoconhecimento em uma experiência web que conecta **identidade, desenvolvimento, futuro e carreira**.

## ✦ Autoria

Projeto desenvolvido por **Laís Cruz** como uma versão digital do projeto **Passaporte para o Futuro**.
